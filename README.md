Biblioteca Escolar CETis 131

Descripción

Aplicación móvil desarrollada en Flutter que permite a los estudiantes consultar el catálogo de libros de la biblioteca escolar, visualizar información detallada y guardar libros favoritos.

Características

- Consulta de libros.
- Búsqueda por título o autor.
- Visualización de detalles.
- Gestión de favoritos.
- Interfaz amigable para estudiantes.

Tecnologías utilizadas

- Flutter
- Dart

Instalación

1. Clonar el repositorio.
2. Abrir el proyecto en Visual Studio Code o Android Studio.
3. Ejecutar:

flutter pub get

4. Iniciar la aplicación:

flutter run

Uso

Abrir la aplicación y navegar por las diferentes secciones para consultar libros, realizar búsquedas y administrar favoritos.
